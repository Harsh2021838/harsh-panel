Harsh panel

For Premiere Pro and After Effects 2022 and later, on Windows and Mac.

Install (once)

Unzip the download first. Keep everything in the folder together.

Windows

  1. Quit Premiere Pro and After Effects.
  2. Double-click Install Harsh (Windows).bat.
  3. If Windows says “Windows protected your PC”, click More info, then Run anyway.
  4. When it says Done, press any key.

Mac

  1. Quit Premiere Pro and After Effects.
  2. Right-click Install Harsh (Mac).command and choose Open, then Open again. (macOS blocks double-clicking it the first time.)
  3. When it says Done, press Enter.

Then open Premiere Pro or After Effects and choose Window > Extensions > Harsh. Dock the panel wherever you like; the app remembers it.

Client DNA

Each client’s brand in one place: logo, website, brand colours, the highlight colour you use in videos, fonts and notes. Choose the client once with the button at the top right of the panel; Client DNA and Assets then show that client.

  1. Open the Client DNA tab and click New (or Add your first client).
  2. Fill in the brand name, founder and website, choose the logo file, and add 3–4 brand colours (pick them or paste the code, like #FF6A3D), the highlight colour and 3–4 fonts with what each is used for. Click Add client.
  • Click a colour to copy its code, ready to paste into Premiere or After Effects.
  • In After Effects, select text or shape layers and click a colour’s brush to apply it. Cmd/Ctrl+Z undoes it.
  • Fonts not installed on this computer are marked, so you know before you start.
  • Import logo puts the logo in a “Harsh / client name” bin (Premiere) or folder (After Effects).

Assets

Files you reuse: stick figures, logos, icons, sounds, templates. Each client has their own assets, and Common holds the ones for everyone.

  • Add files, or drag files from Finder or Explorer onto the panel. Folders you make inside the assets folder (like “Stick figures”) show as groups.
  • Click assets to select them, then Import. Double-click imports one straight away.
  • In Premiere, a selected template (.mogrt) can go straight onto the timeline with At playhead.
  • Remove moves files to the library’s _Removed folder; nothing is deleted.
Everything is saved in your Harsh Library (see Settings).

Text QC

Finds typos and grammar mistakes in on-screen text before you export. Open the QC tab at the bottom of the panel, then Text QC.

In After Effects

  1. Pick what to check: All comps, Selected (select comps in the Project panel first), Folders (untick imported or old folders) or Other projects (add .aep files or a whole folder).
  2. Click Check text. Reading the project takes a moment; the spelling check runs in the background, so you can keep working.
  3. Each mistake is underlined. Click the green suggestion to change it in the layer. If the same text is used in several comps, it changes in all of them.
  4. Go to opens the comp and selects the layer. Add to dictionary stops a name or brand being flagged again.
Every change can be undone with Cmd/Ctrl+Z. If a layer mixes fonts or colours in one line, look at it after the change. Text that comes from an expression has to be fixed in the expression.

In Premiere Pro

One check covers everything Premiere can show on screen:

  • Titles made with the Type tool or Essential Graphics.
  • Templates (MOGRTs): every text field.
  • After Effects comps in the timeline (Dynamic Link or “Replace with After Effects Composition”), including text inside their precomps. The .aep file is read directly; After Effects doesn’t need to be open.
  • Captions: caption files imported into the project are found automatically. For captions made in Premiere (Speech to Text or the caption tool), select the caption track, choose File > Export > Captions, save as .srt, and click Add .srt once.
  1. Pick All sequences or Open sequence (this one also looks inside nested sequences), then click Check text.
  2. Each result shows where it is: the kind (Title, Template, AE comp, Caption), the sequence and the timecode. Go to moves the playhead there and selects the clip.
  3. Fix titles in the Essential Graphics panel and comps in After Effects, then click Check again; only changed text is checked again.
Not checked: Legacy Titles, and text that’s part of a rendered video file. After Effects text driven by an expression is checked as typed, before the expression runs. If a moved .aep can’t be found, the results say so.

Reading the results

  • The big number is how many mistakes need fixing; the coloured bar shows the mix. Review one by one walks through them: → next, ← back, Enter uses the first suggestion (After Effects), G goes to it, I ignores it, Esc closes.
  • Or tap any row in the list to see the full text, every place it appears, and the fix buttons.
  • Typos and Odd characters (invisible characters, missing glyphs, double spaces) are the ones to fix. Grammar is worth a look. Capitals and Unknown words are hidden at first; click them to show.
  • Export report saves a page with every mistake, a per-project summary and the comps with the most problems, to share with the team.
  • Text that hasn’t changed is remembered, so checking again is instant.

Very big jobs

The free spelling server handles about 65,000 characters a minute and waits on its own if a job goes over. For no limit, run LanguageTool on your computer and enter its address (for example http://localhost:8081) in Settings > Spelling server, or add a LanguageTool Premium username and API key.

Settings and your library

Everything the panel saves lives in one folder, the Harsh Library: every client’s DNA, logo, assets, SFX and reusable comps, plus each tool’s own data (like the Text QC dictionary and reports). Open Settings with the gear at the top right.

  • Change location: pick a folder. Choose Copy my library there to move everything (the old folder is left as it is), or point at a folder that already has a Harsh Library, for example on your team’s Dropbox.
  • Save a backup: makes a dated copy of the whole library wherever you choose.
  • Export a client: one folder with everything for that client, to send to someone or move to another computer. Import a client folder brings it in.

Inside the library: Clients/ (a folder per client), Common/ (assets, SFX and comps for every client), Tools/ (each tool’s data) and _Removed/ (anything you remove).

If something goes wrong

  • The panel isn’t in Window > Extensions. Restart the app. Still missing: run the installer again.
  • “Busy, probably with a dialog open”. Close the open dialog in Premiere or After Effects and try again.
  • “Couldn’t be checked”. No internet, or the spelling server was down. Click Check again; only those texts are retried. Settings > Test Connection checks the link.
  • Anything else: message Harsh with a screenshot of the panel.

Updates

New versions come as a Harsh zip (like Harsh-2_5_0.zip). Two ways to install one:

  • Automatically: once an update source is set in Settings > Updates, new versions download by themselves (when the panel opens and every few hours) into the Updates folder.
  • Updates folder: put the zip in the Updates folder of your Harsh Library. The panel finds it when it opens. In Settings > Updates, choose Ask me first (a yellow bar offers Install now) or Install automatically. If your library is on a shared drive, everyone on the team gets it.
  • By hand: Settings > Updates > Install from file and choose the zip.

Before installing, the current version is copied to the library’s _Removed folder, so you can always go back. The panel reloads by itself; if anything looks odd afterwards, restart Premiere or After Effects. Running the installer from the zip also still works.
